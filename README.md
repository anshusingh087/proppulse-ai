# PropPulse AI — Real Estate Market Valuation & Database Engine

🌐 **Live Web Application:** [https://proppulse-ai.onrender.com](https://proppulse-ai.onrender.com)

---

### 📌 Project Overview
An interactive full-stack machine learning web application that estimates residential real estate prices in Bangalore. The tool processes micro-market benchmark rates, property parameters (BHK, super built-up area), down payments, and provides real-time mortgage/EMI estimates with continuous SQLite database logging.

### 🚀 Key Features
* **Dynamic Property Valuation:** Calculates estimated market price using locality-based rate benchmarks (Whitefield, Indiranagar, Electronic City, etc.).
* **Financial EMI & Growth Projections:** Real-time loan stress calculations (8.5% interest, 20-year tenure) and 5-year capital appreciation forecasts.
* **Continuous SQLite Logging:** Persists every prediction record (timestamp, locality, area, BHK, valuation) in `predictions.db`.
* **Full-Stack Deployment:** Python Flask backend with responsive UI deployed seamlessly on Render.
